Engineered Without Compromises

⚡

Dual-Engine Architecture

Instant startup with Tree-Walk Interpreter paired with the optimized Corvus Bytecode VM for compute-intensive tasks.

🌐

Native Networking & Web

Production-ready TCP/UDP sockets, Go-style concurrency channels, and a modular HTTP server with route dispatch & middleware.

🛡️

Gradual Type Safety

Optional type annotations (let x: Number = 42) enforce safety where you want it without cluttering quick scripts.

✂️

Pythonic Slicing

Native array and string slicing (arr[1:4], text[:5]) with negative index support directly in the runtime.

🔐

Pure In-Memory Crypto

Hardware-tuned native SHA-256, MD5, and RFC 2104 compliant HMAC-SHA256 verified against OpenSSL with zero shell hacks.

📦

Rich Standard Library

Over 50 modular packages: Stack, Queue, Deque, PriorityQueue, Trie, BST, WorkerPool, BitSet, JSON, Config, and more.
