# Security Policy

## Supported Versions

Only the latest release of Raven receives security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of Raven seriously. If you discover a security vulnerability, please do NOT create a public issue on GitHub.

Instead, please send an email to:
`security@raven-lang.org` (or open a private GitHub Security Advisory).

Please include:
1. Description of the vulnerability.
2. Minimal `.rvn` reproducible exploit code.
3. Operating system and processor architecture.
4. Expected security impact.

We will acknowledge receipt within 48 hours and work with you to remediate and disclose the issue responsibly.
